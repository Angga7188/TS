01 / STRUCTURAL

Sistem Grid (12-Column Grid System)

Grid adalah kerangka kerja tak terlihat yang terdiri dari kolom, baris, dan jarak antar kolom (gutters). Sistem 12-kolom adalah standar industri karena angka 12 sangat mudah dibagi rata menjadi pecahan: 1/2 (6 kolom), 1/3 (4 kolom), 1/4 (3 kolom), maupun tata letak asimetris (8 + 4).

A. Kerangka Acuan 12 Kolom Dasar (Blueprint)

02 / 1D LAYOUT

Flexbox (Flexible Box Layout)

Modul CSS untuk tata letak satu dimensi (baik baris horizontal atau kolom vertikal). Keunggulannya adalah mendistribusikan ruang sisa secara dinamis dan menyejajarkan elemen dengan sempurna, bahkan saat ukuran item di dalamnya tidak sama atau tidak diketahui.

03 / 2D LAYOUT

CSS Grid Layout (Tata Letak Majalah / Asimetris)

Sistem tata letak dua dimensi yang bekerja pada baris dan kolom secara bersamaan. Sangat unggul untuk desain halaman web yang kompleks dan asimetris seperti majalah (*editorial magazine layout*), di mana satu elemen dapat merentang melintasi beberapa kolom DAN beberapa baris sekaligus.

Contoh Nyata: Tata Letak Editorial Majalah Modern

display: grid; grid-template-columns: repeat(3, 1fr);
BERITA UTAMA (2 Kolom x 2 Baris)

Desain Web Modern Berbasis CSS Grid

Elemen ini menggunakan grid-column: span 2; grid-row: span 2; sehingga menguasai area visual utama secara asimetris.

Pola ini hampir mustahil dibuat dengan rapi hanya menggunakan Flexbox.
SIDEBAR (1 Kolom x 2 Baris)

Opini & Tren

  • CSS Subgrid: Evolusi fleksibilitas hierarki anak.
  • Fluid Typography: Skala teks responsif dengan clamp().
  • Container Queries: Responsif berbasis komponen.
Kolom 1 / Baris 3

Desain Responsif

Tata letak otomatis menyesuaikan ukuran layar tanpa merusak estetika.

Kolom 2 / Baris 3

Aksesibilitas Web

Memastikan urutan visual di layar tetap ramah bagi screen reader pembaca.

Kolom 3 / Baris 3

Performa CSS

Kombinasi Grid + Flexbox menghasilkan struktur DOM yang bersih dan cepat.

Aturan CSS Grid yang Digunakan: 
.magazine-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 Kolom sama besar */
  gap: 16px;
}
.mag-headline {
  grid-column: span 2; /* Membentang 2 Kolom ke samping */
  grid-row: span 2;    /* Membentang 2 Baris ke bawah */
}
.mag-sidebar {
  grid-column: span 1; /* 1 Kolom */
  grid-row: span 2;    /* Membentang 2 Baris ke bawah sejajar headline */
}
RANGKUMAN DOSEN

Kapan Harus Menggunakan Masing-Masing?

Pedoman praktis untuk mahasiswa dalam menentukan arsitektur layout yang tepat.

Parameter 01. Sistem Grid 12-Kolom 02. Flexbox (1D) 03. CSS Grid (2D)
Dimensi Tata Letak Struktural (Kolom vertikal) 1 Dimensi (Baris ATAU Kolom) 2 Dimensi (Baris DAN Kolom serentak)
Tujuan Utama Menjaga konsistensi lebar dan proporsi pecahan konten. Mendistribusikan ruang dan perataan item dalam satu arah. Membangun arsitektur halaman majalah, dashboard, dan galeri asimetris.
Contoh Penggunaan Standar layout Bootstrap, Tailwind, atau wireframe Figma. Navbar, baris tombol aksi, card footer, daftar chat. Halaman artikel majalah, dashboard multi-widget, galeri foto.
Kelebihan Kunci Prediktif dan mudah dibagi (pecahan 12). Item fleksibel meregang menyesuaikan isi konten. Bisa menentukan posisi baris dan kolom secara bersamaan (`span`).
